# TCCs 2026

Repositório para organização das entregas de TCC 2026, contendo trabalhos, apresentações, códigos-fonte e instruções de instalação dos alunos.

## Estrutura do repositório

- `tccs/`: arquivos finais dos TCCs em PDF.
- `apresentação/`: apresentações dos trabalhos (PDF).
- `codigo-fonte/`: arquivos compactados (`.zip`/`.rar`) com os códigos-fonte.
- `instruções de instalação/`: documentos de instalação por aluno (`.pdf` e, em alguns casos, `.txt`).

## Padrão de nomes

Os arquivos seguem o padrão:

`<TIPO> <NOME DO ALUNO> - <MATRÍCULA>.<extensão>`

Exemplos:

- `TCC SERGIO OTÁVIO - 2023319550.pdf`
- `CODIGO-FONTE ANA CLARA - 2023316351.zip`
- `INSTRUÇÕES DE INSTALAÇÃO SERGIO OTAVIO - 2023319550.txt`

## Como consultar um trabalho

1. Abra o arquivo do TCC na pasta `tccs/`.
2. Veja os slides correspondentes na pasta `apresentação/` (quando disponíveis).
3. Extraia o arquivo da pasta `codigo-fonte/` para analisar ou executar o projeto.
4. Siga o documento da pasta `instruções de instalação/` referente ao mesmo aluno.

## Observações

- Nem todos os alunos necessariamente possuem código-fonte ou instruções completas em texto.
- Este repositório funciona como acervo de arquivos entregues.
